FoodIsHard

Dinner, sorted.

FoodIsHard is a small, free, open-source meal planner for vegetarian households. It plans a week of dinners, gives simple recipes (with optional baby-friendly portions), and builds a shared shopping list split by supermarket.

It's a personal hobby project, not a company or a public service. There's no sign-up page: each copy of FoodIsHard is run privately by someone for their own household, family and friends, and you can only use a copy if the person running it invites you.

Signing in

If you've been invited, open the link you were sent and sign in with the email address you were invited with, either with Google or with a one-time code sent by email. There are no passwords.

Running your own copy

The code is free to use on GitHub. It runs as a Home Assistant app or on Cloudflare's free plan. If you run a copy, you're responsible for it and for the people you invite.

Before using it, please read the privacy policy and the terms of use, especially the food safety notes.
